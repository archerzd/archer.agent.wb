
## 修复 Git 连接 GitHub 失败问题（11:08）
- 症状：git HTTPS 操作报 `schannel: CRYPT_E_NO_REVOCATION_CHECK`，网络本身到 github.com/api.github.com 是通的
- 根因：Git SDK 2.55.0（D:/git-sdk-64）默认 schannel 后端下，证书吊销检查（CRL/OCSP）不可达导致连接中断；且不显式设置 `http.sslBackend` 时 `http.schannelCheckRevoke=false` 不生效
- 修复：全局 gitconfig 设 `http.sslBackend=schannel` + `http.schannelCheckRevoke=false`，`git ls-remote` 验证通过
- 备注：openssl 后端方案（curl cacert.pem）在沙箱代理环境不可用，已回退；临时文件 C:/Users/WS/.git-certs/cacert.pem 可留可删
